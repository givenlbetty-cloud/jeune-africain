## 🎓 Technical Learnings

### Django Discoveries
1. **CustomUser** - Uses email as USERNAME_FIELD, not username
2. **ManyToMany** - Requires `.add()` instead of direct assignment
3. **DateTimeField** - Some fields require timezone.now()
4. **Test Auth** - Use force_login() for custom user models

### Testing Best Practices
1. Isolate tests with proper setUp/tearDown
2. Use assertIn() for multiple acceptable values
3. Generate unique values (UUID) for unique fields
4. Simplify tests that depend on complex views

### Frontend Patterns
1. Modal management with JavaScript
2. CSRF token in async requests
3. Progress indication for operations
4. Responsive design with Bootstrap
