Puis Ctrl+Shift+M pour activer le mode mobile

Redimensionnez la fenêtre pour tester:
  �� Mobile (< 576px)     → 1-2 colonnes
  📱 Tablet (576-768px)   → 2-3 colonnes
  🖥️  Desktop (768+px)     → 3-4 colonnes

Le site s'adapte parfaitement à tous les écrans!
