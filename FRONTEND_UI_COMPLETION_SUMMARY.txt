## How Users Will Experience It

### Buying a Book
```
1. Browse book details
2. Click "Acheter" button
3. Payment modal opens (no page reload!)
4. Select payment provider
5. Enter phone number
6. Click "Procéder au paiement"
7. Wait for confirmation from your phone
8. Page automatically reloads
9. Full book access granted!
```

### Reading Free Preview
```
1. Open free book (not purchased)
2. Banner appears: "Prévisualisation Gratuite - Pages 1-20"
3. Progress bar shows reading progress
4. Read pages 1-20 normally
5. Try to read page 21
6. Modal appears: "Limite atteinte - Acheter pour continuer"
7. Click "Acheter" → payment modal opens
8. Complete payment
9. Full access to all 384 pages
```

### Registering for Event
```
1. Go to events page
2. Search for or filter events
3. Click "Détails" on an event card
4. Event modal opens with full details
5. Click "S'inscrire"
6. Success message appears
7. Can now unregister if desired
```
